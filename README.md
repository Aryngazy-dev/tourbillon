# Tourbillon

Канбан-доска с сохранением на сервере. Раньше всё жило в localStorage браузера,
теперь доска хранится в SQLite и отдаётся через маленький Flask-бэкенд, так что
данные не пропадают при чистке кеша и доступны с любого устройства в сети.

## Запуск

```
pip install -r requirements.txt
python3 server.py
```

Откройте http://localhost:8000 — фронтенд отдаётся тем же сервером, отдельно
поднимать ничего не нужно. Порт можно поменять переменной окружения `PORT`.

При первом запуске сервер сам создаёт `tourbillon.db` рядом с `server.py` и
заполняет её демо-задачами. Дальше всё, что происходит на доске — карточки,
колонки, чек-листы, метки, архив — сохраняется в базу с небольшой задержкой
(видно по индикатору рядом с часами в шапке).

## Что внутри

- `server.py` — Flask + SQLite, REST-эндпоинты `/api/board` (GET/PUT) и
  `/api/board/reset`
- `js/api.js` — обёртка над fetch для общения с бэкендом
- `js/state.js` — состояние доски в памяти + отложенная синхронизация с сервером
- остальное — фронтенд без изменений в логике, только визуальные добавления
  (индикатор синхронизации, экран загрузки)

Если сервер недоступен, доска на клиенте всё равно откроется с демо-данными,
просто без сохранения — индикатор покажет «нет связи с сервером».
